One small runtime.
Your app, everywhere.

Write one TypeScript-shaped file. Durable objects hold your state, timers and events. The UI is drawn with native widgets, and the same objects are your backend API. Every host can be driven by AI agents.

Run the demo → Install 
object Counter {
  count: number = 0

  increment(by = 1) { this.count += by }

  // durable timer, survives restarts
  @every("1s") tick() { this.count += 1 }
}

function App() {
  const c = Counter.get("main")
  return <Column padding={16}>
    <Text>Count: {c.count}</Text>
    <Button id="inc" onPress={() => c.increment()}>
      Add one
    </Button>
  </Column>
}

Durable objects

State, @every timers, scheduled alarms and realtime events live on objects. They persist and survive restarts.

Native UI

The runtime owns the view tree and sends small patches. Hosts draw real widgets: DOM, Android Views and UIKit.

Backend included

Every public method is an HTTP endpoint. Mark an object @server and every device gets a live, offline-cached replica of it. Same code, same objects.

Built for agents

A language agents already know, with one way to do each thing. It is type-checked, and errors say how to fix them: 'txt' is not a field of Todo, did you mean 'text'?

Automation built in

Every host exposes the semantic tree, bounds, screenshots, object state and work counters. tj review checks visual accuracy, and tj mcp lets agents drive and test apps.

Tiny

A Rust core with no async runtime. The browser runtime, compiler included, is about half a megabyte. Old devices are in scope.

Where it runs

Updated as each host lands. Old devices are in scope: Android 5.0+, 32-bit ARM, browsers without WebGPU.

Latest

  • Plugins and an AI shop assistant. Capabilities come as plugins: typed modules backed by MCP servers, isolated in their own processes. The durable cart's assistant changes the cart in plain words through Claude, with the key kept on the server.
  • Secure by default. Objects declare who may read them and call each method (@read, @allow, caller), and nothing is open without a rule. API keys, stream tickets and audit lines on the server; tokens on every host. Designed with an independent security review.
  • Apps in several files. import { Cart } from "./cart", the TypeScript way, with errors that say which import to add. The durable cart is now three files.
  • Calls that survive outages. Server calls made offline wait in a durable outbox and run exactly once when the server is back. Replicas resume their change stream instead of refetching, and slow clients never build a backlog.
  • Numbers to optimise. tj bench times boot and rendering and counts the work; a size and speed budget fails any change that makes things worse. The server reports its latency and realtime fan-out lag.
  • One reference for agents. tj docs and the MCP language tool hand an agent the whole language in one call.
  • Right-to-left. Arabic, Urdu and Hebrew layouts mirror on every host: the core flips rows on Android and iOS, the browser follows dir on the web.
  • One layout engine. CSS flexbox computed once in the core for Android and iOS, matching the browser. A screen lays out the same everywhere and can be tested without a device.
  • iOS host. Native UIKit, built and driven on the iOS Simulator in CI for every pull request.
  • Durable cart and smart meter. One cart changed from the UI, the backend, the API and an AI agent, live on every screen. A meter workflow driven by timers, alarms, actions and API events.
  • Testing for agents. tj review catches overflow, overlap, tiny touch targets, missing labels and low contrast. tj mcp lets any coding agent inspect, drive, screenshot and review apps.
  • Server objects. @server object Room lives on the server; browsers and phones hold live, offline-cached replicas. Tested with a chat between a browser and an Android phone.
  • Type checker. TypeScript-style checks with "did you mean" fixes; unannotated code stays any.
  • Linux on ARM. Fully static binaries for 64-bit and 32-bit ARM, about 3.5 MB.
  • C ABI for Apple and desktop hosts. The runtime builds for iOS and macOS today; the UIKit host is next.
  • Android host. Native Views, minSdk 21, four ABIs, a 1.7 MB APK, automation over adb.
  • Web host and live demo. The runtime in WebAssembly, drawing native DOM.

Run it locally

You need Rust 1.80+ and the WASM target. Edit the file, and the page reloads with your objects' state kept.

git clone https://github.com/mindmakr/tinyjump
cd tinyjump
rustup target add wasm32-unknown-unknown
cargo web
cargo tj dev examples/todo/app.tj
# open http://127.0.0.1:4700

curl -X POST localhost:4700/api/Todos/main/add
