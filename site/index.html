01 What it is

One unified runtime. Zero fragile glue between UI, backend, and agents.

tinyjump is an open-source, deterministic runtime written in pure Rust. Its core building block is a durable, observable object that holds state, timers, alarms, access rules, and events — running identically on browsers, phones, and servers.

Traditional App Stack 10+ tools · fragile joins

A web framework, two mobile stacks, a REST/GraphQL API, an ORM, a database, a realtime broker, a job queue, an auth layer, a privacy checklist, and brittle E2E scripts — each with its own language, schema, and failure modes.

Web SPA iOS App Android App API Gateway ORM + Migrations Pub/Sub Broker Cron / Queue Auth Glue PII Spreadsheets Flaky Browser Tests

AI agents can write each part fast — and then spend days debugging the seams between them.

tinyjump Runtime 1 language · 0 I/O in core

One TypeScript-shaped source compiles to small AOT bytecode (.tjb). The I/O-free core computes state, rules, and layout once; thin hosts draw real native widgets and perform disk, network, and crypto I/O.

Durable objects everywhere

State, scheduled alarms, recurring timers, and events live together on objects. Every mutation persists atomically to disk and streams in order to every subscribed screen.

Real native UI, one layout engine

Not a web view. The core computes CSS flexbox layout once (Taffy) with RTL mirroring; hosts render real DOM, Android Views, and UIKit widgets that behave identically everywhere.

Built-in automation & proof

Every host exposes the same semantic tree, object state, controllable clock, and input channel. Agents inspect, drive, screenshot-diff, and verify apps in one deterministic loop.

02 Why it is

Software powers our world and economy — it should be safe, small, and open to everyone.

In the agentic era, writing code is no longer the bottleneck. Trust, reliability, privacy, and maintainability are. We built tinyjump so humans and AI agents can ship dependable systems together without massive cloud complexity.

The joins between ten tools are where apps leak personal data, drop offline work, and break at 2 a.m. Removing the joins makes both humans and AI agents 10× more reliable.

Clinics, local shops, schools, cooperatives, startups, and public institutions everywhere need software that works offline, speaks local languages (including Arabic, Urdu, and CJK), respects personal data laws, and runs smoothly on affordable 10-year-old phones.

Today, delivering that reliability takes a whole platform team and a stack of proprietary cloud services. When the runtime itself guarantees closed-by-default access control, compile-time PII protection, durable state, and live-reload safety, a single founder or a small team collaborating with AI agents can build institutional-grade software — and own every byte on their own Linux server.

Because tinyjump starts clean, there is no legacy bloat: every feature is measured against strict binary size and VM step budgets before it merges.

import { act, Skill } from "tj:agent"

// Every skill maps to an app method under caller's @allow rules.
// Shopper's name is fixed so the model cannot spoof identity.
function skills(name: string): Skill[] {
  const by = { name: `${name} (via the assistant)` }
  return [
    { name: "add", object: "Cart/demo", method: "add",
      params: ["sku", "name"], input: SKU, fixed: by },
    { name: "restock", object: "Shelf/main", method: "stock",
      params: ["sku", "qty"], input: RESTOCK, fixed: {} },
  ]
}

export @server @read("anyone") object Assistant {
  lines: ChatLine[] = []

  @allow("anyone") @exclusive async ask(q: string, name: string) {
    const mem = AssistantMemory.get(this.id)
    const turn = await act(this.instructions(),
      mem.messages.concat([{ role: "user", text: q }]),
      skills(name), MAX_STEPS)
    mem.keep(turn.messages)
    this.say("assistant", turn.text || "Done.")
  }
}

@server @read("anyone") object Slot {
  title: string = ""
  start: number = 0
  minutes: number = 0
  @read("staff", "self") customer: string = ""

  @allow("signedIn") @exclusive async book() {
    if (caller.roles.includes("staff")) { throw new Error("Staff cannot book") }
    this.mustBeOpen()
    const me = Customer.get(caller.id)
    if (me.name === "" || me.phone === "") {
      throw new Error("Save your name and phone before booking")
    }
    this.customer = caller.id
    const before = Settings.get("main").reminderMinutes * 60000
    this.schedule("remind", Math.max(0, this.start - before - Date.now()), "remind")
  }

  @allow("signedIn") @exclusive cancel() {
    this.unschedule("remind")
    this.customer = ""
  }
}

import { erase, exportData } from "tj:privacy"
import { Consent, consented } from "tj:consent"

const lawfulBasis = { account: "contract", news: "consent" }

@server @read("owner") @retain("2y") object Member {
  @pii("contact", "account") name: string = ""
  @pii("contact", "account", "news") email: string = ""

  // Runs only for members who actively consented to "news".
  @needs("consent:news") async newsletter(issue: string) {
    await fetch("https://api.mailer.example/send", {
      method: "POST",
      body: JSON.stringify({ to: reveal(this.email, "news"), template: issue }),
    })
  }

  @allow("owner") async myData(): any { return await exportData(caller.id) }
  @allow("owner") async leave() { await erase(caller.id) }
}

examples/smart-meter/app.tj Timers, alarms & live telemetry 
@server @read("anyone") object Meter {
  state: "normal" | "high" | "alert" = "normal"
  limitKw: number = 5
  acknowledged: boolean = true

  @allow("anyone") record(kw: number, source: string) {
    this.readings.push({ at: Date.now(), kw, source })
    if (this.state === "normal" && kw > this.limitKw) {
      this.state = "high"
      this.schedule(CONFIRM_MS, "confirm")
    }
  }

  // Durable alarm: still high after confirmation window? Escalate!
  private confirm() {
    if (this.state !== "high" || this.average(3) <= this.limitKw) { return }
    this.state = "alert"
    this.acknowledged = false
    this.emit("notice", { level: "alert", kw: this.average(3) })
    this.schedule(ESCALATE_MS, "escalate")
  }
}
