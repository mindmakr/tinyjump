01 Install Agent Skills

One command to teach your agent tinyjump

Choose your agent below. We publish two open-format skills: tinyjump (Builder + Multi-Platform Packager) and an optional companion tinyjump-review (Independent Critic & QA Auditor).

Claude Code (macOS / Linux / WSL)

Installs both the tinyjump builder skill and the optional tinyjump-review critic skill globally into ~/.claude/skills/. Swap ~/.claude/skills for .claude/skills inside a project to keep it repo-scoped.

bash
mkdir -p ~/.claude/skills/tinyjump ~/.claude/skills/tinyjump-review
curl -fsSL https://mindmakr.github.io/tinyjump/skills/tinyjump/SKILL.md \
  -o ~/.claude/skills/tinyjump/SKILL.md
curl -fsSL https://mindmakr.github.io/tinyjump/skills/tinyjump-review/SKILL.md \
  -o ~/.claude/skills/tinyjump-review/SKILL.md

Then invoke directly in Claude Code with /tinyjump (or just ask: "Use the tinyjump skill to build…").

Prerequisites (one-time setup)

Clone tinyjump once so your agent has the tj CLI, WASM runtime, and native hosts locally:

bash
git clone https://github.com/mindmakr/tinyjump
cd tinyjump
rustup target add wasm32-unknown-unknown
cargo web
cargo build --release -p tj-cli

Tip: add target/release to your PATH (or invoke via cargo tj ...).

Optional: Connect tj mcp for live UI driving

Give Claude Code, Antigravity, or Cursor direct MCP tools to inspect the live semantic tree, click buttons, check layouts, and record .trace.jsonl tests against a running app:

mcp.json (Claude Code / Cursor / Antigravity)
{
  "mcpServers": {
    "tinyjump": {
      "command": "tj",
      "args": ["mcp", "--target", "http://127.0.0.1:4700"]
    }
  }
}

Point --target to :4700 (Web), :4701 (Android/iOS debug), :4702 (macOS AppKit), or :4703 (Linux GTK 3).

02 How to Use the Skill

Prompt your agent — it handles the entire build & proof loop

Once the skill is installed, describe the app you want in plain language. The skill directs your agent to read tj docs first, write idiomatic .tj modules, create deterministic .trace.jsonl tests, run multi-locale RTL checks, and package your target builds.

Starter Prompt · Multi-Platform App

"Use the tinyjump skill to build a shared habit & expense tracker in my-app/app.tj with offline-first @server sync, @pii-protected profile fields, English + Arabic RTL locales, and deterministic tests/*.trace.jsonl tests. Verify with tj check --access --privacy, tj test, and tj review --pseudo, then build a static Web bundle and an Android APK."

Optional Second Pass · Blind Critic Review

"Use the tinyjump-review skill to independently audit my-app/app.tj for access-control holes, @pii leaks, missing @exclusive guards, RTL overflow, and offline restart bugs."

Step 1 · Learn & Write

Single-page spec, zero guessing

The skill forces your agent to run tj docs before writing code, avoiding common TypeScript-vs-.tj traps (strict ===, closed-by-default @read+@allow, stable widget ids, and tj:ui forms).

Step 2 · Prove & Replay

Compiler + trace + RTL sweep

Your agent proves types, access matrix, and PII flow with tj check --access --privacy, replays deterministic .trace.jsonl tests in milliseconds with tj test, and catches clipping/contrast bugs with tj review --pseudo.

Step 3 · Package & Ship

One codebase → 6 native targets

With the exact same app.tj, your agent builds AOT Web WASM, Android APKs, zero-Xcode iOS .app bundles, macOS AppKit, Linux GTK 3, and self-hosted server binaries.

1. Web215 KB gz AOTES2017

Web (Live Dev & Static AOT Bundle)

Run locally with hot reload, or package a self-contained static folder (HTML + JS + compiler-free AOT WASM + .tjb) ready for any CDN or static host.

bash
# Live reload dev server (http://127.0.0.1:4700)
cargo web
cargo tj dev my-app/app.tj

# Production static bundle (215 KB gz AOT WASM)
cargo web-aot
cargo tj build my-app/app.tj --web --out dist/web
2. Android531 KB arm64 APKminSdk 21

Android (Turnkey Native APK)

Generates a self-contained plain-Java Gradle project (automatically merging any declared permissions.json device permissions) and assembles an installable APK. Needs Android SDK, NDK, cargo-ndk, and JDK 17.

bash
cargo tj build my-app/app.tj --android --aot \
  --app-id com.example.myapp \
  --title "My App" --version 1.0.0 \
  --abis arm64-v8a \
  --server http://10.0.2.2:4700 \
  --assemble --out dist/android

# Install on connected phone or emulator:
adb install -r dist/android/app/build/outputs/apk/debug/app-debug.apk
3. iOSNative UIKitZero Xcode

iOS (Turnkey Flat .app Bundle)

Emits Info.plist (with automatic camera/location/microphone usage keys), AppDelegate.swift, and precompiled app.tjb, then compiles a runnable iOS Simulator .app on macOS without opening Xcode.

bash (macOS)
cargo tj build my-app/app.tj --ios --aot \
  --app-id com.example.myapp \
  --title "My App" --version 1.0.0 \
  --server http://127.0.0.1:4700 \
  --assemble --out dist/ios

# Install & launch on booted iOS Simulator:
xcrun simctl install booted "dist/ios/My App.app"
xcrun simctl launch booted com.example.myapp

Linux Desktop (Native GTK 3 Host)

Dynamically loads runtime libgtk-3.so.0 (no libgtk-3-dev required at compile time), runs .tj or binary AOT .tjb apps, stores data in $XDG_DATA_HOME/tinyjump, and exposes /_tj/screenshot on :4703.

bash scripts/linux.sh

# Launch your .tj or precompiled .tjb app natively
hosts/linux/target/release/tinyjump-linux \
  --app my-app/app.tj \
  --server http://127.0.0.1:4700
6. Backend ServerSingle BinaryAES-256-GCM

Self-Hosted Server & Live Reload

Serve your @server objects, HTTP API, SSE realtime streams, encryption at rest, and tamper-evident audit logs from one binary — with shadow-booted tj reload upgrades.

bash
# Run directly with scoped API keys
cargo tj key alice --keys keys.json --role staff
TJ_KEYS=keys.json cargo tj serve my-app/app.tj \
  --host 0.0.0.0 --port 4700 --data ./data

# Or ship a single standalone Linux executable with embedded bytecode
cargo tj build my-app/app.tj --linux --out dist/my-app-server

Add Optional Capabilities from the Registry (0 KB overhead when unused)

Browse and pin audited Official packages from mindmakr/tj-plugins (utility modules, regional GDPR/PDPL compliance packs, opt-in device plugins for files, notifications, location, camera, and WebRTC webrtc video calls) or generate a typed bridge from any OpenAPI 3.x spec:

bash
cargo tj search                         # browse all 11 Official packages
cargo tj add money --dir my-app         # pin commit + SHA-256 in tj.lock
cargo tj add camera --dir my-app        # opt-in native camera plugin
cargo tj bridge openapi api.json --out my-app/api.tj
