## Disposition by item

- **`REG-1` (`__fetch` bypass): fixed (`ba225cc`).** `collect_expr_caps` (`registry.rs:987-990, 1066`) unconditionally rejects direct calls and bare references to `__fetch`, even with `permissions.network: ["*"]`.
- **`REG-2` (`Item::Let` pattern defaults): fixed (`ba225cc`).** `collect_program_caps` (`registry.rs:803`) now walks `collect_pattern_caps(&d.pattern, caps)`.
- **`REG-3` (Transitive `tj:agent -> tj:ai` bypass): fixed (`ba225cc`).** Visited-set BFS over `modules::BUILT_IN` (`registry.rs:701-725`) propagates `plugins`, `network_hosts`, `plain_http_urls`, `dynamic_fetch`, `dynamic_plugin`, and `pii`.
- **`REG-4` (`//# file:` bundle marker injection): fixed (`ba225cc`).** `verify_package_source` (`registry.rs:646-654`) rejects `//# file:` lines before parsing/compiling.
- **`REG-5` (`is_loopback_http` & redirect loop): fixed (`ba225cc`).** `is_loopback_http` parses authority strictly (no `@`/`\`, valid `u16` port); `fetch_bytes_https` uses `.redirects(0)` with a ≤5-hop loop validating every `Location` hop before issuing the next request (and protocol-relative/uppercase `Location` headers fail closed onto the current origin).
- **`REG-6` (`extract_https_host`, IPv6 brackets, `HTTP://`): fixed (`ba225cc`).** Rejects `@`/`\`/whitespace, brackets IPv6 as `[{host}]:443`, uses `parts.len() > 1` on templates, and checks `http://` case-insensitively.
- **`REG-7` (Relative `./` imports & skipped `compile`): fixed (`ba225cc`).** Both `verify_package_source` (`registry.rs:670-679`) and `app.rs:31-33` reject non-`tj:` imports; unresolved external `tj:*` imports are also refused so standalone `tj_core::compile` always runs.
- **`REG-8` (`tj check` / `tj serve` enforcement & error accumulation): fixed (`ba225cc`).** `check` (`--manifest --json`, `--against --json`, text), `print_check_reports`, and `serve` all enforce `registry::check_lockfile` and accumulate errors in `Vec<String>`; `load_locked_module` warns on `flagged` packages.
- **`REG-9` (`tj.lock` metadata validation): fixed (`ba225cc`).** `validate_locked_metadata` runs on `load_locked_module`, `check_lockfile`, and `retro_findings`; invalid `permissions.network` entries fail closed.
- **`REG-10` & `REG-11` (Semver, `entry`, GitHub `owner`/`repo`, `PII_CATEGORIES`, control chars, built-in typosquats, canonicalized `index/`): fixed (`ba225cc`).** All verified in `registry.rs:372-428, 535-575, 1351-1364, 1556-1562`.
- **`REG-12` (`add_package` ordering, PID temp files, `tj retro`): fixed (`ba225cc`).** `tj.lock` is read before writing `.tj-packages/`; temp files use `.tmp.<pid>` with cleanup on rename failure; `retro::analyze` runs `registry::retro_findings` before `app::read` and returns structured `[fix]` (`supply-chain`) findings on tampered/missing imports.
- **`REG-13` (Third-party plugin PII transfers in `tj_core::flow`): fixed (`ba225cc`).** `crates/tj-core/src/flow.rs:955-958` maps `plugin("<name>", ...)` to `Destination::Plugin("tj:<name>")` under `#[cfg(feature = "check")]` (no regression to built-in `tj:privacy`, and 0 bytes added to WASM/Android/iOS).
- **`REG-14` (Budget): accepted.** Device builds stayed at 0 bytes added (`tj_wasm.wasm` 794/795 KB, all 4 Android targets unchanged); `target/release/tj` at 8485/8550 KB (65 KB headroom) is justified for the hardening.
