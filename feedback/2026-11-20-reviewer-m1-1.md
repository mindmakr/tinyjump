## About tinyjump

1. `tj review` against `tj serve` says "No findings." while its own metrics show
   `nodes=0`. It checked nothing, and should say so.
2. `inspect()` returns a promise, though `docs/language.md` said "returns". This is
   already fixed on `m1-fixes-1`.
3. The HTTP API does not check arguments against the method's signature:
   - extra arguments are accepted silently;
   - wrong types come back as raw runtime errors, such as "cannot compare string and
     number".
4. Revealed copies of personal data on other objects are invisible to `--privacy`, to the
   retention check, to `tj privacy export` and to `exportData`. Even so, `--compliance`
   reports retention as met. This is the same question as `builder-017` question 1.
5. `--record` lists `app.tj:76` and `:77` eight times each. It also names both fields for
   a line that reveals one.
6. There is no `tj --version`, and `tj review --help` answers "unknown option". The help
   part is already fixed on `m1-fixes-1`.
7. The web app cannot reload while offline (`net::ERR_INTERNET_DISCONNECTED`): there is no
   offline page shell. Only an open tab keeps showing slots, and nothing on screen says
   that actions are queued.
